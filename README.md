# Islam Diab · Portfolio

Personal site: https://islam-diab.github.io/portfolio/

React 18, Vite and Tailwind CSS 4. Deployed to GitHub Pages by `.github/workflows/deploy.yml` on every push to `main`.

## Editing content

- All text, links and projects: `src/content.ts`
- Layout: `src/App.tsx`
- Images: `src/assets/` (WebP, about 600px wide for app screens)
- CV served by the "CV (PDF)" links: `public/Islam-Salama-Diab.pdf`

## Run locally

```bash
npm install
npm run dev
```
